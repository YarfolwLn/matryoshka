# Матрешка - SPA для заказа сувениров

Single Page Application для сервиса заказа сувениров "Матрешка", разработанное на Vue.js 3.

## Быстрый старт

### Для разработки с локальным API:

```bash
# Запуск API сервера
cd api-server
npm install
npm start

# В другом терминале - откройте index.html в браузере
```

Не забудьте изменить `src/api.js`:
```javascript
const API_BASE = 'http://localhost:3000';
```

## Технологии

- **Vue.js 3.x** - фреймворк для построения интерфейса
- **Vue Router 4.x** - маршрутизация
- **Bootstrap 5** - стилизация
- **Animate.css** - анимации
- **SweetAlert2** - красивые уведомления
- **localStorage** - сохранение состояния (авторизация, корзина)

## Функциональность

### Каталог товаров
- Отображение всех товаров из каталога
- Адаптивный интерфейс в зависимости от роли пользователя:
  - Неавторизованный: ссылки на регистрацию и вход
  - Авторизованный: ссылка на выход
  - Клиент: кнопки добавления в корзину, ссылка на заказы
- Анимации при наведении на товары
- Уведомления при добавлении в корзину

### Регистрация
- Форма регистрации с валидацией
- Подсветка ошибок красным цветом
- Текстовые сообщения об ошибках
- Переход на экран входа после успешной регистрации

### Вход в систему
- Форма авторизации с валидацией
- Подсветка ошибок красным цветом
- Сохранение токена и данных пользователя
- Переход на домашний экран после успешного входа

### Корзина
- Отображение добавленных товаров
- Группировка одинаковых товаров с указанием количества
- Кнопки увеличения/уменьшения количества
- Удаление товаров из корзины
- Подсчет итоговой суммы
- Оформление заказа с переходом на экран заказов

### Оформленные заказы
- Список всех заказов пользователя
- Детальная информация о каждом заказе
- Статусы заказов с цветовой индикацией
- Дата и сумма заказа

## API интеграция

Приложение взаимодействует с API по адресу: `http://xxxxxx-m2.wsr.m1/api-souvenir`

### Локальный API сервер

В проекте включен локальный API сервер для разработки и тестирования. Для его запуска:

```bash
cd api-server
npm install
npm start
```

После запуска сервер будет доступен по адресу: `http://localhost:3000`

Для подключения фронтенда к локальному API серверу, измените в `src/api.js`:
```javascript
const API_BASE = 'http://localhost:3000';
```

Подробная документация API сервера находится в `api-server/README.md`.

### Доступные эндпоинты:

- `GET /products` - получение списка товаров
- `POST /register` - регистрация нового пользователя
- `POST /login` - вход в систему
- `GET /orders` - получение заказов пользователя (требует авторизации)
- `POST /orders` - создание заказа (требует авторизации)
- `POST /logout` - выход из системы

## Установка и запуск

### Вариант 1: С локальным API сервером (рекомендуется для разработки)

1. Запустите API сервер:
```bash
cd api-server
npm install
npm start
```

2. Измените API endpoint в `src/api.js`:
```javascript
const API_BASE = 'http://localhost:3000';
```

3. Откройте `index.html` в браузере

### Вариант 2: С внешним API (для продакшна)

1. Склонируйте или загрузите файлы проекта
2. Замените `xxxxxx` в `src/api.js` на ваш логин участника:
```javascript
const API_BASE = 'http://ВАШ_ЛОГИН-m2.wsr.m1/api-souvenir';
```
3. Откройте `index.html` в браузере

### Развертывание на сервере

1. Загрузите все файлы проекта на сервер в директорию `public_html` или аналогичную
2. Убедитесь, что `index.html` находится в корне директории
3. Приложение будет доступно по адресу: `http://xxxxxx-n2.wsr.m1`

Где `xxxxxx` - ваш логин участника.

## Настройка API

Перед развертыванием необходимо отредактировать файл `src/api.js`:

```javascript
const API_BASE = 'http://ВАШ_ЛОГИН-m2.wsr.m1/api-souvenir';
```

Замените `ВАШ_ЛОГИН` на ваш реальный логин участника.

## Особенности реализации

### Управление состоянием
- Используется простой store на основе JavaScript объектов
- Состояние сохраняется в localStorage (авторизация, корзина)
- Реактивность через подписки на изменения состояния

### Анимации и UX
- Плавные переходы между экранами (Animate.css)
- Анимации при наведении на товары
- Красивые уведомления (SweetAlert2)
- Индикаторы загрузки
- Подтверждение действий (удаление из корзины)

### Безопасность
- Токен сохраняется в localStorage
- Защищенные маршруты (корзина, заказы требуют авторизации)
- Автоматический редирект на страницу входа для защищенных маршрутов

### Валидация форм
- Проверка обязательных полей
- Проверка формата email
- Проверка длины пароля
- Подтверждение пароля при регистрации
- Визуальное отображение ошибок

## Требования к браузеру
