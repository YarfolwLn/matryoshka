# Инструкция по развертыванию

## Перед развертыванием

### 1. Настройка API endpoint

Откройте файл `src/api.js` и замените `xxxxxx` на ваш логин участника:

```javascript
const API_BASE = 'http://ВАШ_ЛОГИН-m2.wsr.m1/api-souvenir';
```

**Пример:** Если ваш логин `ivanov`, то:
```javascript
const API_BASE = 'http://ivanov-m2.wsr.m1/api-souvenir';
```

### 2. Проверка файлов

Убедитесь, что у вас есть следующая структура файлов:

```
/
├── index.html
├── README.md
├── .gitignore
├── config.example.js
└── src/
    ├── main.js
    ├── router.js
    ├── store.js
    ├── api.js
    └── components/
        ├── Catalog.js
        ├── Register.js
        ├── Login.js
        ├── Cart.js
        └── Orders.js
```

## Развертывание

### Вариант 1: Загрузка через FTP/SFTP

1. Подключитесь к серверу по FTP/SFTP
2. Перейдите в директорию `public_html` или аналогичную
3. Загрузите все файлы проекта
4. Убедитесь, что `index.html` находится в корне директории

### Вариант 2: Через панель управления хостинга

1. Войдите в панель управления (cPanel, Plesk и т.д.)
2. Откройте файловый менеджер
3. Перейдите в `public_html`
4. Загрузите все файлы проекта
5. Проверьте права доступа к файлам (обычно 644 для файлов, 755 для директорий)

### Вариант 3: Через Git (если доступно)

```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin <URL-вашего-репозитория>
git push -u origin main
```

## Проверка работоспособности

После развертывания:

1. Откройте браузер и перейдите по адресу: `http://ВАШ_ЛОГИН-n2.wsr.m1`
2. Проверьте загрузку главной страницы (каталог товаров)
3. Попробуйте зарегистрироваться
4. Войдите в систему
5. Добавьте товары в корзину
6. Оформите заказ
7. Проверьте список заказов

## Возможные проблемы и решения

### Проблема: Белый экран

**Причина:** Ошибка в JavaScript
**Решение:** Откройте консоль браузера (F12) и проверьте наличие ошибок

### Проблема: API не работает

**Причина:** Неверный API endpoint
**Решение:** Проверьте файл `src/api.js` и убедитесь, что логин указан правильно

### Проблема: Стили не загружаются

**Причина:** CDN недоступен
**Решение:** Проверьте подключение к интернету

### Проблема: Маршрутизация не работает

**Причина:** Проблемы с hash-режимом
**Решение:** Убедитесь, что Vue Router настроен с `createWebHashHistory()`

## Локальное тестирование

Для тестирования локально:

1. Откройте `index.html` в браузере (двойной клик)
2. Или используйте локальный сервер:
   - Python: `python -m http.server 8000`
   - Node.js: `npx http-server`
   - PHP: `php -S localhost:8000`
