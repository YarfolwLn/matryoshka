# API Server for Matryoshka Souvenir Shop

Backend API server for the Matryoshka souvenir shop SPA application.

## Технологии

- **Node.js** - runtime environment
- **Express.js** - web framework
- **JWT** - authentication tokens
- **bcryptjs** - password hashing
- **CORS** - cross-origin resource sharing

## Установка

1. Перейдите в директорию api-server:
```bash
cd api-server
```

2. Установите зависимости:
```bash
npm install
```

## Запуск

### Режим разработки (с авто-перезагрузкой):
```bash
npm run dev
```

### Продакшн режим:
```bash
npm start
```

Сервер будет запущен на порту 3000 (или на порту, указанном в переменной окружения PORT).

## API Эндпоинты

### Публичные эндпоинты

#### GET /products
Получение списка всех товаров.

**Ответ:**
```json
[
  {
    "id": 1,
    "name": "Матрешка классическая",
    "description": "Традиционная русская матрешка ручной росписи",
    "price": 2500,
    "image": "https://images.unsplash.com/photo-..."
  }
]
```

#### POST /register
Регистрация нового пользователя.

**Тело запроса:**
```json
{
  "email": "user@example.com",
  "password": "password123",
  "name": "Иван Иванов"
}
```

**Ответ:**
```json
{
  "message": "Регистрация успешна",
  "user": {
    "id": 2,
    "email": "user@example.com",
    "name": "Иван Иванов",
    "role": "client"
  }
}
```

#### POST /login
Вход в систему.

**Тело запроса:**
```json
{
  "email": "user@example.com",
  "password": "password123"
}
```

**Ответ:**
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": 2,
    "email": "user@example.com",
    "name": "Иван Иванов",
    "role": "client"
  }
}
```

### Защищенные эндпоинты (требуют авторизации)

Для доступа к защищенным эндпоинтам необходимо добавить заголовок:
```
Authorization: Bearer <token>
```

#### GET /orders
Получение заказов текущего пользователя.

**Ответ:**
```json
[
  {
    "id": 1,
    "userId": 2,
    "items": [
      {
        "productId": 1,
        "name": "Матрешка классическая",
        "price": 2500,
        "quantity": 2
      }
    ],
    "total": 5000,
    "status": "pending",
    "createdAt": "2024-01-15T10:30:00.000Z"
  }
]
```

#### POST /orders
Создание нового заказа.

**Тело запроса:**
```json
{
  "items": [
    {
      "productId": 1,
      "quantity": 2
    }
  ]
}
```

**Ответ:**
```json
{
  "message": "Заказ успешно оформлен",
  "order": {
    "id": 1,
    "userId": 2,
    "items": [...],
    "total": 5000,
    "status": "pending",
    "createdAt": "2024-01-15T10:30:00.000Z"
  }
}
```

#### POST /logout
Выход из системы.

**Ответ:**
```json
{
  "message": "Выход выполнен успешно"
}
```

### Служебные эндпоинты

#### GET /health
Проверка работоспособности сервера.

**Ответ:**
```json
{
  "status": "ok",
  "timestamp": "2024-01-15T10:30:00.000Z"
}
```

## Начальные данные

При запуске сервер автоматически инициализируется с:

### Товары (6 штук):
1. Матрешка классическая - 2500 руб.
2. Матрешка "Зимняя сказка" - 3200 руб.
3. Матрешка "Цветочная" - 2800 руб.
4. Матрешка "Гжель" - 3500 руб.
5. Матрешка "Хохлома" - 3800 руб.
6. Матрешка мини - 1500 руб.

### Администратор:
- Email: admin@matryoshka.ru
- Пароль: admin123
- Роль: admin

## Валидация

### Регистрация:
- Email: обязательное поле, должен содержать @
- Пароль: обязательное поле, минимум 6 символов
- Имя: обязательное поле
- Email должен быть уникальным

### Вход:
- Email: обязательное поле
- Пароль: обязательное поле

### Создание заказа:
- Корзина не должна быть пустой
- Все товары должны существовать в каталоге

## Настройка

### Переменные окружения:

- `PORT` - порт сервера (по умолчанию: 3000)
- `JWT_SECRET` - секретный ключ для JWT токенов (по умолчанию: 'your-secret-key-change-in-production')

**Важно:** В продакшене обязательно измените JWT_SECRET на сложное случайное значение.

## Интеграция с фронтендом

Для подключения фронтенда к этому API серверу:

1. Запустите API сервер:
```bash
cd api-server
npm install
npm start
```

2. Отредактируйте файл `src/api.js` в фронтенде:
```javascript
const API_BASE = 'http://localhost:3000';
```

3. Откройте `index.html` в браузере

## Примечания

- Данные хранятся в памяти (при перезапуске сервера данные сбрасываются)
- Для продакшена рекомендуется использовать настоящую базу данных (PostgreSQL, MongoDB и т.д.)
- Токены JWT действуют 24 часа
- Пароли хешируются с использованием bcrypt
